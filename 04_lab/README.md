## 备份与回滚策略（重要：Player 不支持快照）

> 本机是 VMware Workstation **Player 17**，快照是 **Pro** 才有的功能。
> 实测 `vmrun snapshot` 返回"此操作不受支持"，图形界面也没有入口。
> **替代方案：关机后复制虚拟机文件夹**，脚本已备好：`scripts/backup-vm.ps1`。

| 对象 | 策略 |
|---|---|
| 攻击机（Kali/Ubuntu） | 装完工具后备份一次 `scripts\backup-vm.ps1 -Name "Ubuntu 64 位"`；以后环境炸了直接恢复 |
| 本地靶机 | 每次开工前 `scripts\backup-vm.ps1 -Name phpblog`，备份在 `04_lab\images\_backup\phpblog_clean\` |
| 在线靶机（THM/HTB） | 用完即销毁实例，不保留 |

**备份时虚拟机必须关机。** 开机复制会得到损坏的磁盘。

**回滚不是洁癖**：靶机被自己改坏、被 exploit 打崩是常态。有备份，你敢乱试；没备份，你会在每个操作前犹豫，效率反而更低。

## 网络

- 攻击机与靶机统一走 VMware NAT 网段，**不要让靶机桥接到物理网络**。
- 固件仿真（firmadyne / FirmAE）默认会起独立网桥，跑完记得清理，避免和真实网段冲突。
- 实验网段与实验室 `Seed Intelligent Analysis` 的实体设备网段（见其《实验环境网络配置流程》）**物理隔离**，不要混用。
