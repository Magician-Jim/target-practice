# phpblog 开工指引（W45 · Baby）

> 本文件是 [打法手册](../../00_meta/打法手册.md) 在这一台机器上的**实例化版本**。
> 原则：给决策树和检查点，不给答案。第一台的价值在于"自己走通"，不在于"快速看到 flag"。
> 总预算：**3 小时**。Baby 难度超过 3 小时，说明方法有问题，不是机器有问题。

---

## 阶段 0：环境（20 分钟）

1. **下载并校验**：QQ 文件下到本地，确认是完整 OVA（大小对得上、不是分卷缺卷）。放 `04_lab\images\`，不要放桌面。
2. **导入**：VirtualBox → 管理 → 导入虚拟设备 → 选 `.ova`（若拿到的是 `.vbox`，用「添加」直接挂载）。
3. **网络**：靶机使用 **Host-only**；Kali 使用 `NAT + Host-only` 双网卡，两块 Host-only 必须选择同一个适配器。不要桥接到物理网络。
4. **拿 IP**（三选一）：
   - 靶机控制台登录后 `ip a`
   - Kali：`sudo arp-scan -I <Host-only网卡> 192.168.56.0/24`
   - VirtualBox 图形界面：靶机窗口右下角网络图标或 `VBoxManage list dhcp`
5. **连通性**：Kali `ping <IP>` 通了再往下。不通先查网段，别急着扫。
6. **备份一份干净副本**：VirtualBox 中生成快照 `clean`；需要整机归档时再关机执行 `.\scripts\backup-vm.ps1 -Name phpblog`。然后记下开始时间。
7. **开终端记录**（防事后想不起敲了什么）：

```bash
script -a ~/phpblog_session.log
```

## 阶段 1：侦察（30 分钟）

```bash
IP=<靶机IP>

nmap -p- --min-rate 2000 -T4 $IP -oN 01_recon/nmap_all.txt
nmap -sC -sV -p<上一步的开放端口> $IP -oN 01_recon/nmap_svc.txt
whatweb http://$IP -v > 01_recon/whatweb.txt
curl -sI http://$IP > 01_recon/headers.txt
ffuf -u http://$IP/FUZZ -w /usr/share/wordlists/dirb/common.txt \
     -mc 200,301,302,403 -o 01_recon/ffuf_dir.json
```

**重点看什么**：

- 80 / 8080 上跑的是什么博客程序？页面 footer、`/readme.html`、`/CHANGELOG` 有没有版本号
- `/robots.txt`、`/.git/`、`/www.zip`、`/backup.sql`、`/db.sql`（**Baby 难度最爱在这里放源码**）
- `admin/`、`login.php`、`upload.php`、`phpmyadmin/`
- 22 端口开着 → 记下 SSH banner 版本（后面可能用得上）

**判据**：Baby 难度，题眼几乎一定在 80 端口的 web 应用本身，不在服务层。**不要在 SMB/NFS/内核版本上浪费时间**，那是 Medium 以后的事。

## 阶段 2：立足点（60 分钟）——决策树

按你侦察到的东西往下走，**只走一条，走不通再换**：

```
web 应用
├─ 有登录框 ──────→ 弱口令：admin/admin、admin/123456、admin/password、admin/admin888
│                    有注册功能 → 注册普通用户，看后台/上传是否有越权
├─ URL 带 ?id= ?page= ?cat= ──→ SQLi
│                    '  /  1 and 1=1  /  1 and 1=2  /  sleep(3)
│                    有回显走联合/报错，无回显走布尔/时间
├─ 参数像文件名 ──→ LFI
│                    ../../../../etc/passwd
│                    php://filter/convert.base64-encode/resource=index.php
├─ 有上传点 ──────→ 后缀绕过（.php5/.phtml/.php.）、Content-Type 改 image/jpeg
│                    图片马 + .htaccess、文件名截断
├─ 是 WordPress ──→ wpscan --url http://$IP --enumerate u,p,vp
├─ 自写程序 ──────→ 先找源码泄露（备份包/源码包），本地审计 include / exec / SQL 拼接
└─ 有 phpMyAdmin ─→ root 空密码 / 弱口令 → SELECT ... INTO OUTFILE 写 shell
                     （前提 secure_file_priv 允许、目录可写）
```

**拿到 shell 后第一组命令**（背下来）：

```bash
id; hostname; uname -a; cat /etc/os-release; ip a
python3 -c 'import pty;pty.spawn("/bin/bash")'
```

> 如果只拿到 flag、没拿到 shell，也算阶段完成，但笔记里必须写清：flag 从哪读到的、为什么不需要 shell。

## 阶段 3：提权（45 分钟）

**顺序不能跳**，跳了就会像我见过的很多人一样，在 linpeas 输出里翻半小时却漏掉 `sudo -l` 一行：

1. `sudo -l`
2. `find / -perm -4000 -type f 2>/dev/null` → 丢 GTFOBins
3. `crontab -l; cat /etc/crontab; ls -la /etc/cron.*`
4. `getcap -r / 2>/dev/null`
5. 配置与凭据：`.bash_history`、`config.php`、`wp-config.php`、`.ssh/`
6. 内核版本 → **最后**再考虑 exp（容易崩机）

Baby 难度大概率在第 1 或第 2 步就结束。
