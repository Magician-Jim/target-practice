# 命名与归档约定

> 目的：半年后回来找东西，不用回忆当时怎么起的名字。

---

## 一、目录命名：`YYYY-Www_平台-靶机名`

```
2026-W45_THM-BasicPentesting
2026-W46_THM-Kenobi
2026-W47_HTB-Meow
2026-W48_VH-Kioptrix1
```

| 字段 | 规则 |
|---|---|
| `YYYY-Www` | ISO 周次。`new-target.ps1` 自动算，不用手填 |
| 平台 | `THM` / `HTB` / `VH`(VulnHub) / `VULHUB` / `IOT` |
| 靶机名 | 保留官方原名，去空格，用 `-` 连接，大小写按官方 |

**一周两台**：`2026-W47_HTB-Meow` 和 `2026-W47_HTB-Fawn`，都保留 W47，自然并列。

---

## 二、文件命名

| 位置 | 命名 | 例子 |
|---|---|---|
| `01_recon/` | `<工具>_<对象>.txt` | `nmap_all.txt`、`nmap_svc.txt`、`whatweb.txt`、`ffuf_dir.txt` |
| `02_exploit/` | `<漏洞名>_<用途>.py` / `.sh` | `cve-2019-11043_poc.py`、`upload_shell.php` |
| `03_privesc/` | `<来源>_<内容>` | `sudo_l.txt`、`suid_list.txt`、`linpeas.txt` |
| `04_loot/` | 原名 | `root.txt`、`hash.txt`（git 忽略） |
| `05_evidence/` | `<序号>_<说明>.png` | `01_webshell.png`、`02_root_proof.png` |
| `03_knowledge/` | 一文件一主题，中文名 | `linux/SUID-提权.md`、`web/文件上传绕过.md` |

> 知识卡片用中文名，因为半年后你搜的是概念，不是英文拼写。

---

## 三、周报命名：`打靶机周报-MM.DD至MM.DD_姓名`

继承实验室既有规范（母本：`iotamoeba项目周报-10.12至10.18_黄子沣.md`）：

```
打靶机周报-11.02至11.08_黄子沣.md
打靶机周报-11.02至11.08_黄子沣.pdf
```

- 周期按**周一至周日**
- 日期用 `MM.DD`，用 `至` 连接，不用 `-`
- 导出副本存 `02_reports/`，源文件是 `01_targets/<靶机>/REPORT.md`

---

## 四、状态标签（全目录统一）

| 标签 | 含义 | 用在哪 |
|---|---|---|
| ✅ | 已解决 / 独立完成 | 周报结论列、INDEX |
| 🟡 | 借助提示完成 | INDEX |
| 🔄 | 有进展 / 进行中 | 周报结论列、INDEX |
| ⚠️ | 无进展 / 未完成 | 周报结论列、INDEX |
| ❓ | 待老师确认 | 周报第四部分 |
| ⏸ | 暂停 | INDEX（须写原因） |

---

## 五、归档时机

| 时机 | 动作 |
|---|---|
| 每台靶机打完 | 回滚快照；`04_loot/` 留档但不入 git；`03_knowledge/` 至少补 1 条 |
| 每 4 周 | 回看 INDEX，统计 ✅ 比例与耗时趋势 |
| 学期末 | `01_targets/` 整体移入 `05_archive/2026秋/`；`03_knowledge/` 整理成《IoT 漏洞挖掘入门笔记》 |

---

## 六、Git 规范

本目录可独立 `git init`，将来推到 `git.cuc.edu.cn`。提交信息用 Conventional Commits：

```
feat(W45): scaffold Basic Pentesting
docs(W45): add recon notes
docs(W45): publish weekly report
fix(W45): correct privesc root cause
chore: update knowledge index
```

| 规则 | 说明 |
|---|---|
| 大文件不进 git | 虚拟机、固件、ISO 已在 `.gitignore` 里排除 |
| 战利品不进 git | `04_loot/` 全忽略，flag 和凭据不对外 |
| 原始扫描输出可以进 | `01_recon/` 的文本文件是复盘证据，值得版本化 |
| 一天一提交 | 过程可回溯比提交信息漂亮更重要 |
